      (0.8,-1.8) -- (0.8,-0.6);

\caption{Traducción a SQL y autocorrección. La consulta que escribe el modelo
nunca llega directamente a la base de datos: pasa por una capa que comprueba
que sea una única sentencia de lectura y la ejecuta sobre una conexión
\texttt{mode=ro}. Si SQLite devuelve un error, ese error se le entrega al
modelo como resultado de la herramienta y corrige en la vuelta siguiente,
dentro del tope de ocho iteraciones por turno.}
